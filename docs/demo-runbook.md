# Loan Origination & Underwriting Copilot — Demo Runbook

This runbook guides a live or asynchronous evaluation walkthrough of the copilot. It adheres strictly to the **Evidence-in-Repo** discipline: all demonstrations are classified as either **`[INSPECT]`** (reading committed, immutable evidence generated by code) or **`[RERUN]`** (safely repeatable live executions).

## Offline Fallback Mode (Section 16.2)
If live model endpoints or network connectivity are unavailable during grading, run the offline reader to inspect committed evidence without live API calls:
```bash
python scripts/show_evidence.py --application APP-001
```
Output displays the selected policy, SHA256 verified citations, calculated DTI, risk screening flags, deterministic recommendation, human review audit trail, and Phoenix trace spans directly from committed files.
